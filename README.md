A house cat writes a one-star review of its human: the lap — the cat's
favourite piece of infrastructure — went offline mid-nap without warning,
so the cat escalates the complaint to the dog.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program writes one deterministic line (no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22, standard library only, no
network access.
